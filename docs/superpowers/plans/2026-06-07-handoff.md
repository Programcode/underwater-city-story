## Architecture facts you need (already verified — trust these)

- Cinematic view: `src/components/CinematicStage.tsx` → `src/components/MapCamera.tsx`.
  `MapCamera` renders `/assets/map.jpg` (5632×3072) inside `.map-camera__drift`,
  then positions `Actor` portraits at percentage coordinates. Actors counter-scale
  with the CSS var `--inv` (= `1 / zoom`) so they keep size at any camera zoom.
- A scene (`StoryScene` in `src/types.ts`) has an optional `locationHotspotId`.
  `CinematicStage` resolves it via `getHotspot(...)` (`src/data/mapHotspots.ts`)
  to a `Focus = {x,y}` percentage; the camera zooms/pans there using
  `computeCameraTransform` in `src/lib/camera.ts`. `arrangeActors` lays out the
  present characters around that focus.
- `CinematicStage` is **remounted per scene** (keyed by scene id in `App`), so any
  cross-scene animation (e.g. walking between places) must live in `App` or a
  wrapper that survives the scene swap.
- Characters: `src/data/characters.ts` (ids: `mira`, `ocean`, `torin`, `veyr`;
  each has accent colour, sprite class, resting position). `getCharactersForScene`
  maps scene id → present characters.
- Audio at runtime is **fully local and offline**: `useNarration`
  (`src/hooks/useNarration.ts`) plays files from `public/audio/voice/` via
  `public/audio/manifest.json`, keyed by `clipKey(speaker,text)` = `` `${speaker}|${text}` ``.
  It only calls the live ElevenLabs proxy as a fallback when a clip is missing.
- The **offline generator** is `scripts/generate-audio.ts` (run: `npm run audio`).
  It reads the API key from `.env.local`, collects every dialogue line, skips
  clips that already exist on disk, fetches the rest, and writes the manifest.
- Ambience today is **procedural, per-mood only** (`AmbienceEngine` in
  `src/lib/ambience.ts`) — NOT per place. SFX (`src/hooks/useSfx.ts`) plays one
  mood sting; the six files in `public/audio/sfx/` are **identical placeholders**
  (all 112,893 bytes) and must be replaced.
- Reduced motion is already threaded everywhere as a `reduced` boolean
  (`useReducedMotion`). Every animation must honor it.

## Decisions already made (do not relitigate)

1. **Voices = ElevenLabs free tier.** The expressive flagship voices and models
   are available on the free tier; paid only removes the monthly cap and adds
   commercial rights / cloning. The full spoken corpus is ~8,400 characters, which
   fits within the free 10k/month cap (worst case 1–2 months once narrator
   paragraphs are included). The existing generator already supports stop/resume
   across months (it skips existing clips). **No ToS circumvention** (no cracked
   keys, reseller keys, or multi-account cap-dodging) — that is out of scope and
   forbidden.
2. **Free-tier output is non-commercial and requires attributing ElevenLabs.**
   Add an attribution line in the credits/README. If commercial use is ever
   needed, swap the generator backend to a freely-licensed local model
   (**Kokoro-82M**, Apache-2.0) — Plan 2 §7 describes the swap; keep `clipKey`,
   the manifest shape, and `public/audio/voice/` identical so app code is untouched.
3. Both feature plans are **purely additive**: the game must remain fully playable
   with zero scene art, zero animation, and zero audio files present.
